# 0.24.0（69）Mac 核心版

根据 Mac 设计包新增独立的 macOS 14+ 目标 `CatLifeMac`，提供标题、小家、布置、打工、商店、猫町、猫咪和设置八个桌面页面。医院、任务、背包、邻居、活动、一起玩及备份恢复沿用现有原生面板。使用真实目录、玩家状态和已提交回执，不使用原型中的演示奖励或云同步状态。

两端共用 `CatGameCore`、Store、美术和音频。存档 schema 仍为 15；Mac 使用独立 Bundle ID 和本地目录，iOS 的 Bundle ID、目录与现有进度不变。Mac 可以通过原生备份手动转移进度，不自动合并存档。

桌面支持鼠标选择、双击近看、右键菜单、滚轮与触控板缩放、拖动家具、目录拖放、四向转向、网格、撤销与重做。窗口最小内容尺寸 1280×720，提供窗口/无边框/全屏、界面缩放、帧率限制和可修改快捷键。后台保留时间结算，停止房间绘制；通知默认关闭，由玩家主动授权。

新增的“提前结束打工”先同步时间，尚未完成时没有工资、不退回开工消耗；已经到期则沿用正常结算。所有改变进度的操作仍通过现有保存流程，失败不会部分扣费。补齐了跨页面返场的楼层门控、休息/醒来入口、缺粮进入用品分类，以及切猫失败后不继续执行右键动作。

## 本次审查修订

- P2 按键重复：仅家具微调和列表移动允许系统重复，购买、照顾、切猫等动作每次按下只触发一次；也阻止 Return/空格的重复落到原生按钮。Tab、空格、Return 不再占作默认游戏命令，游戏确认用 ⌘Return，切猫/近看/列表选择使用 Option 组合；方向键在画布未聚焦时交还原生控件。
- P3 存档：Release、Debug、UI 测试分目录，标题询问实际仓库；加载前检查已有同 Bundle 实例并持有目录文件锁。锁失败不加载或覆盖存档，UI 夹具清理保留锁文件。无法阻止不具备此保护的旧包被用户另行启动，因此手动验收前请退出旧试玩包。
- P3 退出：设置保存与 Store 共用五秒等待期限，超时明确提示尚未确认保存，可取消或仍然退出；迟到的保存任务不会重复回复退出请求。
- P3 点击：仅点猫需要等待双击间隔，食盆、家具、空地立即响应。

为这些修订补充了 13 项回归测试源代码，但遵照用户停止自动化测试的要求未执行。Mac Debug 与测试源码编译、Mac Release 通用构建及 iOS Debug 构建均已通过；未启动 App 或模拟器，也未执行任何测试。**P2 验证项仍未完成，不据此合并或发布。** iOS 进食动画的旧超时复跑、Mac 逐页验收与 Intel 实机检查继续待确认。正式上架前的更新链接、观察测试入口和性能事项也仍保留。

## 最新设计包修订（Mac v1.2）

封面改为全窗昼夜背景、悬挂木牌和真实存档房间；继续按钮显示陪伴猫、游戏天数、等级、猫数与上次回家时间。第一次进入和加载分别呈现，加载少于 0.5 秒不显示五爪印加载页。封面使用独立只读场景，继续后接正面全屋视角。

房间改成 12×7 横向娃娃屋：后墙、左右墙、地板厚度、两个窗、通往猫町的固定门及 6 级解锁的固定楼梯。正面和左右 24° 共用房间、逆向点击映射和取景规则，支持 0.45 秒视角淡出/淡入、滚轮连续缩放、平移及约 1.7 倍近看；减少动态效果下直接切角。首页与布置在同一画布四角放控件。二楼使用浅紫墙面。采用已有木地板、墙纸、窗、家具和猫咪素材，不把原型示意截图当游戏房间。

用户确认 Mac 基础每层 16 件、升级继续扩容：等级 1–8 每层为 **16 / 19 / 23 / 27 / 31 / 31 / 35 / 39** 件，6 级起两层分别布置。升级页、背包、布置与保存使用同一规则；iOS 容量保持原值。运行时容量和展示坐标不写入备份，schema 保持 15。新小家按三分区摆放已有赠品，不额外赠送原型道具；已有布局仅调整门前、楼梯和碰撞冲突，优先就近挪位，无处可放的收进背包，朝向及已获回忆保留。调整和导入先规划候选、成功保存后再发布，失败保留原进度。

本轮按用户要求没有运行测试，也没有启动 App、模拟器或浏览器验收。Core 及测试源码编译、Mac Debug 与测试源码编译、Mac arm64/x86_64 Release 和最终 iOS Debug 编译均成功；282 份运行资源检查及本地包签名核对通过。新增测试只编译、未执行。完整视觉、键鼠手感、首次/再次加载和旧档布置继续由用户手动确认。打工、商店、猫町、猫咪与设置五页在新旧交接包中没有新增改版范围，本轮保留既有实现。

## Claude 修订整理（2026-11-12）

本次在 `22e94f9` 之后追加 Claude 的 16 个修改文件，沿用未发布的 0.24.0（69），不替换此前提交历史。以下描述仅针对这批增量；上文的历史验证结果不作为本次通过依据。

- Mac 房间里的猫、家具和食盆按横向房间统一缩小显示，地面碰撞占地使用同一缩放常量；铺开木地板与墙纸纹理，减少材质被整面拉伸的观感。归一化存档坐标、schema 15 和 iOS 尺寸计算不变。
- 修复首页与布置页交接画布时，保留的布局规划请求未恢复、界面可能一直停在“处理中”的问题。仅在画布激活且仍有请求时恢复，沿用原有规划中的去重判断。
- 首页调整楼层与在家猫数、三视角胶囊、照顾状态和需求高亮、每日任务及最近三条动态；多猫切换仍通过现有 Store 保存流程。
- 布置页统一工具按钮和筛选外观，未选中家具时列出当前楼层已摆放物品；打工中改为统一时钟与进度圆环，展示本次工作的金币、经验和通知状态，结算沿用引擎。
- 猫町地图补上草地、河流、桥梁、道路、广场和玩家位置标记；封面调整月亮、渐变和按钮阴影，设置采用统一的分段选择样式。
- 新建小家不再误显示“旧布局已修复”提示；修正 Debug 单元测试宿主的存档目录隔离判断。新增界面文案同时提供简体中文、繁体中文和英语。

本次 Mac arm64 Debug 与 iOS arm64 Debug（模拟器 SDK）编译均成功；`git diff --check`、三语 key 与格式参数核对通过，16 个 Claude 源文件与整理前副本逐字节一致。没有执行自动化测试，没有启动模拟器或自动操作游戏，也没有重新构建 Release／Intel 包。整套视觉、操作、存档回归、Intel 和密集房间性能仍待手动验收。原始差异恢复副本、源码摘要及编译日志保存在仓库外，不随 PR 上传。
