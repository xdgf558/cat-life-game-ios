# 0.24.0（69）Mac 核心版

根据 Mac 设计包新增独立的 macOS 14+ 目标 `CatLifeMac`，提供标题、小家、布置、打工、商店、猫町、猫咪和设置八个桌面页面。医院、任务、背包、邻居、活动、一起玩及备份恢复沿用现有原生面板。使用真实目录、玩家状态和已提交回执，不使用原型中的演示奖励或云同步状态。

两端共用 `CatGameCore`、Store、美术和音频。存档 schema 仍为 15；Mac 使用独立 Bundle ID 和本地目录，iOS 的 Bundle ID、目录与现有进度不变。Mac 可以通过原生备份手动转移进度，不自动合并存档。

桌面支持鼠标选择、双击近看、右键菜单、滚轮与触控板缩放、拖动家具、目录拖放、四向转向、网格、撤销与重做。窗口最小内容尺寸 1280×720，提供窗口/无边框/全屏、界面缩放、帧率限制和可修改快捷键。后台保留时间结算，停止房间绘制；通知默认关闭，由玩家主动授权。

新增的“提前结束打工”先同步时间，尚未完成时没有工资、不退回开工消耗；已经到期则沿用正常结算。所有改变进度的操作仍通过现有保存流程，失败不会部分扣费。补齐了跨页面返场的楼层门控、休息/醒来入口、缺粮进入用品分类，以及切猫失败后不继续执行右键动作。

## 本次审查修订

- P2 按键重复：仅家具微调和列表移动允许系统重复，购买、照顾、切猫等动作每次按下只触发一次；也阻止 Return/空格的重复落到原生按钮。Tab、空格、Return 不再占作默认游戏命令，游戏确认用 ⌘Return，切猫/近看/列表选择使用 Option 组合；方向键在画布未聚焦时交还原生控件。
- P3 存档：Release、Debug、UI 测试分目录，标题询问实际仓库；加载前检查已有同 Bundle 实例并持有目录文件锁。锁失败不加载或覆盖存档，UI 夹具清理保留锁文件。无法阻止不具备此保护的旧包被用户另行启动，因此手动验收前请退出旧试玩包。
- P3 退出：设置保存与 Store 共用五秒等待期限，超时明确提示尚未确认保存，可取消或仍然退出；迟到的保存任务不会重复回复退出请求。
- P3 点击：仅点猫需要等待双击间隔，食盆、家具、空地立即响应。

为这些修订补充了 13 项回归测试源代码，但遵照用户停止自动化测试的要求未执行。Mac Debug 与测试源码编译、Mac Release 通用构建及 iOS Debug 构建均已通过；未启动 App 或模拟器，也未执行任何测试。**P2 验证项仍未完成，不据此合并或发布。** iOS 进食动画的旧超时复跑、Mac 逐页验收与 Intel 实机检查继续待确认。正式上架前的更新链接、观察测试入口和性能事项也仍保留。
