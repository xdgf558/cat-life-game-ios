# 0.24.0（69）Mac 核心版

根据 Mac 设计包新增独立的 macOS 14+ 目标 `CatLifeMac`，提供标题、小家、布置、打工、商店、猫町、猫咪和设置八个桌面页面。医院、任务、背包、邻居、活动、一起玩及备份恢复沿用现有原生面板。使用真实目录、玩家状态和已提交回执，不使用原型中的演示奖励或云同步状态。

两端共用 `CatGameCore`、Store、美术和音频。存档 schema 仍为 15；Mac 使用独立 Bundle ID 和本地目录，iOS 的 Bundle ID、目录与现有进度不变。Mac 可以通过原生备份手动转移进度，不自动合并存档。

桌面支持鼠标选择、双击近看、右键菜单、滚轮与触控板缩放、拖动家具、目录拖放、四向转向、网格、撤销与重做。窗口最小内容尺寸 1280×720，提供窗口/无边框/全屏、界面缩放、帧率限制和可修改快捷键。后台保留时间结算，停止房间绘制；通知默认关闭，由玩家主动授权。

新增的“提前结束打工”先同步时间，尚未完成时没有工资、不退回开工消耗；已经到期则沿用正常结算。所有改变进度的操作仍通过现有保存流程，失败不会部分扣费。补齐了跨页面返场的楼层门控、休息/醒来入口、缺粮进入用品分类，以及切猫失败后不继续执行右键动作。

## 已完成验证

以下结果均发生在用户要求停止自动化测试之前，没有把未完成的 UI 回归记为通过。

| 范围 | 结果 |
| --- | --- |
| 共享 Core | 459 项测试、48 个套件通过，包含提前结束打工的到期、扣费和防重复结算 |
| Mac App | 最新一轮 30 项通过，覆盖设置、快捷键、缩放、通知去重、撤销重做、保存失败、图像解码与房间返场 |
| 资源与工程脚本 | 20 项通过；282 份运行资源已具备实际内容 |
| iOS App 回归 | 全量 419 项中 418 项通过；一项进食动画在并发负载下超时，单独复测通过，不记作全量全绿 |
| Mac 实际界面 | Debug 实例已走通小家、打工、商店、猫町、玩耍选择、免费一起玩及结果返回；未完成逐页验收 |

Mac UI 自动回归遇到系统动态加载器和前台实例归属问题，没有取得四项全部通过的结果。额外的自定义启动器已移除，保留标准 XCTest 启动代码。收到用户停止指示后已结束测试及隔离实例，之后只整理代码与构建产物，不再运行测试或自动操作界面。

## 待玩家手动验收

重点检查首次启动与再次启动，八个页面，开始/提前结束工作、睡觉/醒来、购买后布置、拖放/转向/撤销重做、跨楼层、一起玩、导入导出，以及 1280×720、三语和 125%/150% 缩放。另需在密集家具、五只猫和多个视角下观察持续性能；Intel Mac 仍需实机运行确认。
