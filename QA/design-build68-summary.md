## 真实动作与设计核对

真实 SpriteKit 时钟覆盖猫窝/坐垫 × 四朝向 × 三视角，直接测渲染 clone 的足点、座面、嘴部和食物表面；验证输入节点、原尺寸/warp 与路径未被渲染层改写，完成/退出回调各一次。保留少量真实 SKView 帧并放大核对，未用拼接模型图替代运行证据。

过程失败已修正并保留在仓库外：小屏操作栏、最大字号滚动/命中区域、Undo 的堵路校验、后台半次事务、无选中食盆工具、视角胶囊遮挡和描边停在旧位置。旧测试的屏幕坐标、自动弹回、缺失按钮查询、数字格式及全局节点查找也改为对应的新行为；没有将失败或未重跑的历史像素测试写成通过。

源图与实际状态的核对见 [design-qa.md](../design-qa.md)。原始截图、xcresult、日志、设计包和 1024 渲染原图均留在仓库外；公开改动仅含摘要、必要的模型源码、运行时裁剪 PNG 与锚点/表面元数据，图片走既有 Git LFS。

## 旧镜像布局审查复验

旧实现已在真实窄通道复现：18/18 个初版对照案例因占地变化而失去路线。修复采用保留原占地，不挪动旧家具、不放宽边界或保存校验。实际移动、收纳或显式转向后，单件家具才启用新的四向占地；描边、预览、规划与持久化使用同一规则。

新增 5 个几何测试方法覆盖 276 组场景（80 组贴墙、80 组相邻、20 组窄通道、16 组休息进出、80 组主动移动边界），同时包含大小屏、两层和多级房屋。新增 Store/Scene 测试覆盖食盆单独保存、另一楼层、微小坐标往返、主动释放、撤销/取消、失败重试和回调前几何一致性。本轮完整 App 419 项全通过，包含上述新增 10 个方法。大小屏真实 UI 均通过仅改食盆后的保存/冷启动、单件转向后取消/再冷启动；同时复验小屏既有四向撤销和无效摆放拦截。

本轮首次完整 App 回归为 418 通过 / 1 失败：新增测试按数组顺序比较两层家具，而既有保存流程会先合并另一层。改为按实例 ID 排序后逐项比较完整位置和楼层，再完整重跑 419 项，全通过；未改生产保存顺序或放宽内容断言。DEBUG 测试包及 iOS Release（不签名）重新构建通过，并确认新夹具启动字符串不在 Release 中。
